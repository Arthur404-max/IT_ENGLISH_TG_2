# IT English Lab — portfolio

Статический клиентский кейс приложения: визуальный тур по реальным экранам, ключевые возможности и краткое техническое подтверждение.

## Как открыть

Откройте `portfolio/index.html` в браузере. Для проверки ссылки на демо-сборку удобнее запустить статический сервер из корня репозитория:

```powershell
# любой статический сервер; пример с Python
python -m http.server 8080
# затем откройте http://127.0.0.1:8080/portfolio/
```

Ссылка «Скачать демо» ведёт на `../dist/it-english-lab.exe`. Это локальная демо-сборка без подписи, не официальный релиз. Официальный подписанный релиз готовится отдельно. Если портфолио публикуется без папки `dist`, замените ссылку на страницу релизов или уберите кнопку.

## Что внутри

- `index.html` — разметка кейса.
- `styles.css` — тёмно-зелёная/лаймовая визуальная система, адаптив от 360 px.
- `app.js` — переключение восьми экранов тура, клавиатурная навигация, reveal-анимации.
- `assets/` — 12 используемых скриншотов текущей сборки.

Страница не использует внешние шрифты, CDN или сторонние библиотеки. Основные данные на экранах — **демонстрационные** (seed), а не метрики реальных пользователей. В подписях и футере это указано явно. Не добавляйте вымышленные отзывы, логотипы клиентов или пользовательские цифры.

### Перегенерация

Скрипт использует временную копию данных, а не живой `%APPDATA%\ITEnglishLab`. Для локального ИИ папка моделей подключается junction-ссылкой только на чтение:

```powershell
$data = Join-Path $env:TEMP "opencode\itelab-portfolio-data"
Remove-Item $data -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Path $data | Out-Null
New-Item -ItemType Junction -Path (Join-Path $data "models") `
  -Target (Join-Path $env:APPDATA "ITEnglishLab\models") | Out-Null

node tools/portfolio_shots.js --seed --ai --data-dir $data --out "portfolio/assets"
```

Требования: Node 22+ (встроенный `WebSocket`), Microsoft Edge, собранный `dist/it-english-lab-embedded.exe`. Перед пересборкой закройте запущенное приложение. Без `--ai` скриншот `15-tutor.png` не создаётся — сохраните существующий файл или запустите с локальной моделью. Скрипт больше не создаёт неиспользуемые кадры.

## Проверки перед публикацией

- Не называйте демо-сборку официальным или подписанным релизом.
- Не публикуйте скриншоты с демо-цифрами как реальную статистику.
- Обновите числа, если изменились данные или тесты: сейчас в кейсе указаны 15 юнитов, 312 терминов, 60 Q&A, 141 speaking-промпт (51 фраза + 90 вопросов), 5 WAV-уроков, 392 smoke-проверки и 106 E2E-проверок.
- Проверьте адаптив на 1440, 1024, 912, 768, 390 и 360 px: горизонтального скролла быть не должно.
- Lighthouse (Accessibility, Best Practices, SEO): 100 / 100 / 100 на текущей версии страницы; перепроверьте после правок.
- Проверьте, что ссылка на демо ведёт на существующий файл и что рядом с ней остаётся пометка «не официальный подписанный релиз».
