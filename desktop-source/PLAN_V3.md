# IT English Lab — план v3

Статус: завершён. Базовая версия v2 зафиксирована коммитом `baseline: IT English Lab v2`; итоговые проверки v3 — smoke 300/300, embedded smoke 293/293, E2E 77/77 и обе release-сборки.

Цель v3 — сделать обучение более точным и управляемым: заменить упрощённый SM-2 на FSRS, ограничить дневную нагрузку, автоматически выносить проблемные слова в отдельную колоду, добавить диагностику и недельный план, а также дать разбор ошибок с объяснением и мини-дриллом. Все обязательные функции должны работать офлайн и без ИИ.

## Принципы

- Сохраняется обычная и embedded-сборка.
- `progress.json` v2 читается и мигрирует в v3 без потери слов, экзаменов и статистики.
- Старые поля `box`, `interval_days`, `ease_factor` остаются в JSON для совместимости и аналитики.
- Новые API и UI не требуют ИИ; ИИ остаётся необязательным помощником.
- PWA-кэш обновляется, статические аудиофайлы работают офлайн после кэширования.

## Риски и решения

- **Старые данные.** Миграция только добавляет поля; при сомнительных значениях используются безопасные дефолты. Исходный файл копируется в backup до миграции.
- **Огромные аудиофайлы.** Используются короткие локальные WAV (16 кГц, моно) и ленивое кэширование PWA.
- **Сложность FSRS.** Реализуется компактная проверяемая версия формулы с явными константами; legacy-поля остаются для отображения.
- **Перегрузка дневной нагрузки.** Все сессии стартуют из серверной очереди, а не собираются заново на клиенте.
- **E2E-нестабильность.** Тесты используют CDP без внешних зависимостей, фиксированные viewport и явные ожидания.
