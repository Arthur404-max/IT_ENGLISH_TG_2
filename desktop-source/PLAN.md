# План улучшений IT English Lab

Статус: **выполнено 12.11.2026**

Цель: сделать экзаменационный блок полноценным: с историей, честным экзаменационным режимом, разбором ошибок, источниками, аудированием/произношением, конструктором экзамена, мобильным доступом и автоматическими smoke-тестами.

## Принятые решения

- **Режим по умолчанию — тренировка.** Экзаменационный режим включается отдельно; в нём ответы и образцы показываются только после завершения.
- **История экзаменов хранится в `progress.json`** и попадает в экспорт/импорт прогресса. Храним последние 100 попыток.
- **Черновик текущей попытки — в `localStorage`.** Это позволяет продолжить экзамен после перезагрузки страницы; аудио в историю и черновик не попадает.
- **Таймер считается от абсолютного дедлайна** (`deadlineAt`), а не уменьшением счётчика раз в секунду. После сворачивания вкладки или сна ПК время не «замирает».
- **Открытые ответы в экзаменационном режиме проверяются после завершения:** показывается образец, пользователь ставит «Зачесть / Не зачесть», затем считается итог.
- **Источники** берутся из `data/units.json`: Unit, название темы, при наличии — текст. Это ссылка на раздел курса, а не внешний источник.
- **Аудио остаётся локальным:** запись через `MediaRecorder` не загружается на сервер и не сохраняется в историю. Для образцов используется существующий TTS браузера.
- **Мобильный доступ — опциональный флаг `--lan`.** По умолчанию сервер слушает только `127.0.0.1`; при `--lan` — `0.0.0.0` с предупреждением, что приложение доступно всем в локальной сети. Для выбора адреса используется `if-addrs`: приоритет у Wi-Fi/Ethernet и приватных IPv4, VPN/виртуальные адаптеры понижаются.
- **ИИ не обязателен.** Все новые функции проверки работают без ИИ.
