# IT English Lab — план v4

Статус: v4 завершён: FSRS-персонализация, speaking-практика, голос/TTS и
релизная инженерия готовы. Официальная публикация по тегу требует
PFX-сертификата в secrets; без него workflow выпускает только unsigned
dry-run artifact.

Цель v4 — усилить ядро обучения, не ломая локальный и офлайн-режим: сделать
расписание FSRS настраиваемым под ученика, затем добавить speaking-практику и
улучшить работу с голосом. Схема прогресса остаётся v3: новые поля являются
необязательными и получают безопасные значения по умолчанию.

## Принципы

- Обычная и embedded-сборка должны собираться и проходить smoke/E2E.
- `progress.json` v1/v2/v3 читается без потери слов, экзаменов и статистики.
- Новые настройки работают офлайн, без AI и без внешних сервисов.
- Изменение настроек не переписывает уже назначенные сроки карточек: новые
  интервалы применяются после следующего ответа.
- Записи речи не загружаются на сервер и не попадают в прогресс; для микрофона
  используется secure context (localhost или HTTPS Tailscale Serve).
- PWA-кэш обновляется при изменении статических ассетов.

### 4. Релизная инженерия

- [x] CI-сборка embedded на Windows: `.github/workflows/release.yml` собирает
  plain и embedded exe, запускает Rust-тесты, smoke plain и smoke embedded.
- [x] Проверка подписи и артефактов релиза: `tools/release.ps1` формирует zip,
  `SHA256SUMS.txt`, `.sha256` и `SHA256SUMS-release.txt`;
  `tools/verify_release.ps1` проверяет архив, файлы и Authenticode. Тег
  требует валидную подпись, ручной запуск без сертификата даёт только
  unsigned artifact.
- [x] Безопасное обновление без доступа к приватному репозиторию из приложения:
  приложение не обращается к GitHub и не хранит токены;
  `tools/install_release.ps1` проверяет пакет, блокируется при запущенном exe,
  делает резервную копию старого exe и не трогает прогресс.

Критерий приёмки: release workflow собирает обе версии и проходит smoke; пакет
проверяется по SHA-256 и подписи; установка возможна только после остановки
приложения и сохраняет бэкап; автообновления и доступа приложения к репозиторию
нет.
